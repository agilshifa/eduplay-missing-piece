EDUPLAY - MISSING PIECE (REVISI)
================================

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Buka folder eduplay_missing_piece di Visual Studio Code.
3. Buka index.html.
4. Klik kanan lalu pilih Open with Live Server.
   Jika belum tersedia, pasang ekstensi Live Server di VS Code.
5. Alternatif: buka index.html langsung melalui browser.

STRUKTUR
- index.html : struktur halaman website
- style.css  : desain dan responsivitas
- script.js  : alur permainan, timer, skor, dan rapor
- assets/    : 8 gambar objek realistis lokal

PERUBAHAN
- Emoji pada ikon tutorial dihilangkan.
- Panel tingkat kesulitan di halaman awal dihilangkan.
- Judul arena permainan diposisikan di tengah.
- Bar HUD (skor/nyawa/streak) di arena dihilangkan dari tampilan.
- Objek emoji diganti gambar objek realistis.
- Jumlah objek meningkat: tahap 1 = 4, tahap 2 = 6, tahap 3 = 8.
- Permainan tetap terdiri dari 15 ronde (5 ronde per tahap).
- Tidak ada sistem nyawa; permainan berlanjut sampai 15 ronde selesai.

CATATAN
Rapor adalah ringkasan performa permainan, bukan diagnosis atau tes psikologi terstandar.
